# BLKOUT: Tactical Operations Center

Unofficial, fan-made browser companion for **BLKOUT** by Enemy Spotted Studios: team builder, unit forge, live game dashboard, and a solo narrative campaign engine with importable campaign packs.

> Not affiliated with or endorsed by Enemy Spotted Studios. No official card data ships with this app; players load their own data packs.

**Live:** https://campberj.github.io/blackout-toc/

```bash
npm ci
npm run dev    # local dev server
npm run ci     # lint + typecheck + test + build
```
